PARALLEL VIEW / 5つの認知を辿る

使い方
1. このフォルダをVS Codeで開く
2. Live Serverでindex.htmlを開く
3. 同じフォルダに47分の動画を「parallel-view.mp4」という名前で置く

今回の実装
- 黒背景・白文字
- 15個の発言をカード状に一覧表示
- 秒数が分かっている発言だけ動画へジャンプ可能（現在は00:20のみ）
- 秒数が未入力の発言は「--:--」で表示
- 発言者が未入力のものは「話者未入力」と表示
- 00:20の「立ち入り禁止〜」には樹形図を接続
- 樹形図はクリックして拡大表示・ズーム可能
- PCでは複数カードを同時に表示、スマートフォンでは1列に切り替え

秒数を後から入れる場合
script.js の voices 配列で、該当する発言の
  time: "",
  seconds: null,
を例えば
  time: "12:34",
  seconds: 754,
のように変更してください。
